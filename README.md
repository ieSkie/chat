# AI Chat

Простой чат с ИИ на React + Express, использующий Gemini API.

## Стек

- Frontend: React (Vite)
- Backend: Express
- API: Google Gemini

## Демо

https://chat-alpha-three-18.vercel.app

## Локальный запуск

### Backend

cd backend
npm install

# создать .env с GEMINI_API_KEY и MODEL

node server.js

### Frontend

cd frontend
npm install

# создать .env с VITE_API_URL

npm run dev
